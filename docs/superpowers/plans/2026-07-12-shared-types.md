# Shared API Contract Types Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `server/src/types.ts` the single source of truth for the API contract, with `web/src/types.ts` generated from it and CI failing on drift.

**Architecture:** A zero-dependency Node script at the repo root regenerates the web mirror (write mode) or verifies it (`--check` mode, used by a new parallel CI job). No new npm package, no workspaces, no Docker/compose/lockfile changes.

**Tech Stack:** Node 22 (plain `.mjs`, `node:fs`/`node:path` only), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-07-12-shared-types-design.md`

## Global Constraints

- Work on the existing `shared-types` branch; commit after each task.
- No commit trailer (project preference: omit Co-Authored-By).
- The script must have zero npm dependencies — no root `package.json`, no lockfile.
- The generated file is ordinary linted TypeScript — no `eslint-disable` in the header.
- Do not change any wire shapes; only comments and file provenance change. `ApiError` appearing in the web copy is expected (it is part of the contract; nothing in `web/` references the name yet).
- Normalize CRLF→LF when reading/comparing (Windows dev machines check out CRLF; CI checks out LF) and write LF.
- All npm commands run inside `server/` or `web/`, never at the repo root.

- [ ] **Step 2: Create `scripts/sync-types.mjs`**

```js
#!/usr/bin/env node
/**
 * Regenerates web/src/types.ts from server/src/types.ts — the single
 * source of truth for the API contract. Zero dependencies by design so it
 * runs on any Node without an install step.
 *
 *   node scripts/sync-types.mjs          rewrite the mirror
 *   node scripts/sync-types.mjs --check  exit 1 with a diff if stale
 */
import { readFileSync, writeFileSync } from "node:fs";
import { dirname, join } from "node:path";
import { fileURLToPath } from "node:url";

const root = join(dirname(fileURLToPath(import.meta.url)), "..");
const sourcePath = join(root, "server", "src", "types.ts");
const mirrorPath = join(root, "web", "src", "types.ts");

const GENERATED_HEADER = `/**
 * GENERATED FROM server/src/types.ts — DO NOT EDIT.
 * Edit the server copy, then run: node scripts/sync-types.mjs
 */
`;

const normalize = (text) => text.replace(/\r\n/g, "\n");

const source = normalize(readFileSync(sourcePath, "utf8"));
// The mirror gets its own header in place of the source file's.
const body = source.replace(/^\/\*\*[\s\S]*?\*\/\n/, "");
const expected = GENERATED_HEADER + body;

if (process.argv.includes("--check")) {
  let actual;
  try {
    actual = normalize(readFileSync(mirrorPath, "utf8"));
  } catch {
    console.error(`missing ${mirrorPath} — run: node scripts/sync-types.mjs`);
    process.exit(1);
  }
  if (actual === expected) {
    console.log("web/src/types.ts is in sync with server/src/types.ts");
    process.exit(0);
  }
  console.error("web/src/types.ts is stale — run: node scripts/sync-types.mjs\n");
  const actualLines = actual.split("\n");
  const expectedLines = expected.split("\n");
  const count = Math.max(actualLines.length, expectedLines.length);
  for (let i = 0; i < count; i++) {
    if (actualLines[i] !== expectedLines[i]) {
      console.error(`line ${i + 1}:`);
      console.error(`  expected: ${expectedLines[i] ?? "<missing>"}`);
      console.error(`  actual:   ${actualLines[i] ?? "<missing>"}`);
    }
  }
  process.exit(1);
}

writeFileSync(mirrorPath, expected);
console.log(`wrote ${mirrorPath}`);
```
